🚀 PRÊT À UTILISER
════════════════════════════════════════════════════════════════════════════

1. Compiler:
   .\Build\Build.ps1 -Configuration Release

2. Lancer:
   .\Bin\LuzReception.exe

3. Importer OPERA:
   • Menu Fichier > Importer XML
   • Voir Bin/Data/SAMPLE_OPERA.tsv pour format

4. Tester:
   • Saisir client manuellement (Onglet 1)
   • Importer fichier test (Onglet 2)
   • Consulter KPIs (Onglet 3)
